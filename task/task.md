## (名前2) — Daytona 担当

**役割**: エージェントがコードを編集する開発環境を用意し、手順を共有する

**いまやっていること**:

**タスク**

- [ ] アカウント作成、APIキー発行
- [ ] サンドボックスを作成し、SSHで入れることを確認する
- [ ] サンドボックスから Nosana のURLに届くか確認する
- [ ] OpenCode を入れ、Nosana を接続先に設定する
- [ ] リポジトリをクローンし、小さな編集を1つエージェントにやらせる
- [ ] 依存を入れた状態をスナップショット化する

**ほかの人から待っているもの**: サービスURL、モデルID ← (名前1)

**完了条件**: 手順どおりにやれば、別のメンバーも同じ環境でエージェントを動かせる

## (名前3) — オーケストレーター担当

**役割**: 生成→実行→判定のループと、ツール固有の処理を実装する

**いまやっていること**:

**タスク**

- [ ] `generate`: Nosana を呼び、応答からコードを抜き出す(最初はモックで可)
- [ ] `run`: Daytona サンドボックスで実行し、結果を返す(最初はモックで可)
- [ ] `judge`: 終了条件を判定する
- [ ] `loop`: 上限とタイムアウト付きで回す
- [ ] 実物の Nosana と Daytona につないで1タスク完走させる
- [ ] ツール固有の処理を実装する(プロンプト、実行コマンド、失敗ログの戻し)
- [ ] サンプル3件で動作確認する

**ほかの人に渡すもの**: 実行方法、デモ用のサンプル → 全員

**ほかの人から待っているもの**: サービスURL、モデルID ← (名前1) / Daytona APIキー、スナップショット名 ← (名前2)

**完了条件**: 課題を入力すると、生成→実行→判定が自動で回って結果が出る
